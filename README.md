# nemotron-speedmap

Ускоряем инференс моделей NVIDIA Nemotron на бесплатном железе и составляем карту: какой приём,
на каком устройстве и насколько ускоряет генерацию. Каждое ускорение проверяем и по скорости,
и по качеству ответов.

*A map of what speeds up NVIDIA Nemotron inference on free hardware (Kaggle T4, a laptop iGPU, CPU), measured for both speed and answer quality.*

## Модели

| Группа | Модели | Где считаем |
|---|---|---|
| 1. Плотные гибриды Mamba-Transformer | Nemotron Nano 9B v2, Nemotron 3 Nano 4B | Kaggle 2× T4, ноутбук, Mac, ПК |
| 2. MoE, которые запускаются у себя | Nemotron 3 Nano 30B-A3B, Lightning 3.5 (30B-A3B) | ноутбук с Radeon 780M, Kaggle 2× T4 |
| 3. Super | Nemotron 3 Super 120B-A12B, Nemotron 3.5 Super VL | только API Nebius: согласие с Nano, токены и деньги, но не скорость |

## Как мерим

- Генерация по одному запросу упирается в память: потолок ток/с ≈ пропускная способность памяти ÷ байты,
  прочитанные на токен. В каждом замере пишем долю от потолка.
- База и варианты — в одном запуске, на одном устройстве; повторы чередуются, прогрев не считается.
- «Без потерь» проверяем сравнением ответов с базой; методы, которые меняют ответы, — всегда вместе с точностью.

Полностью — [`docs/core_api.md`](docs/core_api.md), раздел «Правила замера».

## Быстрый старт

```bash
pip install -e "core[dev]"     # ядро и инструменты разработки
ruff check                     # стиль
pytest                         # тесты без сети, денег и GPU
```

Дополнительно: `core[hf]` — torch и transformers для прототипов, `core[api]` — клиент API Nebius.
Тесты с пометками `network`, `paid`, `gpu` и `slow` по умолчанию выключены; включить, например, так: `pytest -m network`.
