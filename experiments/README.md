# Эксперименты

Один эксперимент — одна папка `ГГГГ-ММ-ДД-имя/`, например `2026-10-21-moe-spec-cost/`. Дата — день начала,
имя — латиницей через дефис.

## Что в папке

| Файл | Что в нём |
|---|---|
| `README.md` | гипотеза, семейство, конфиг, результат, выводы, что дальше (шаблон ниже) |
| `config.yaml` | что запускать — формат в `docs/core_api.md`, раздел 3; начать проще с готового из `core/templates/` |
| `run.py` | только если идея не укладывается в конфиг; пишется на функциях ядра `fastinfer` |
| `results/` | только сводки: `result.json` и другие небольшие `.json` |

Сырые данные (`per_prompt.jsonl`, `env.json`, логи) — на Hugging Face, в датасете `results` команды.
В репозиторий их не кладём: туда идут только сводки (`.gitignore` пропускает только `results/*.json`).

## Шаблон README.md

```markdown
# Название

- **Семейство:** номер и название из docs/families.md
- **Гипотеза:** что проверяем и чего ждём — с числом, которое можно опровергнуть
- **Конфиг:** config.yaml (устройство, модель, квант, варианты)
- **Где и когда:** устройство, коммит, ссылка на сырые данные на HF

## Результат

Таблица из result.json: скорость, доля от потолка, ускорение с интервалом, совпадение с базой или точность.

## Выводы

Что подтвердилось, что нет и почему.

## Что дальше
```

## Правила

- Изменения — через PR; задача на запуск ссылается на конкретный коммит.
- База и варианты — в одном запуске, на одном устройстве (`docs/core_api.md`, раздел 9).
- Методы, которые меняют ответы, — всегда со скоростью и точностью вместе.
- Неудачные прогоны тоже записываем: выборочных прогонов без записи не бывает.
