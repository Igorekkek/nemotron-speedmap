# Диспетчер

Небольшая программа на Python и SQLite на сервере Игоря (1 ГБ RAM, работает постоянно). Принимает задачи
на запуск, ведёт очередь, запускает Kaggle через API, раздаёт задачи агентам на своих устройствах, считает
часы Kaggle и деньги API, шлёт уведомления в Telegram. Сам ничего не считает и моделей не хранит.

Как устроен — `docs/infra.md`. Кода пока нет: по плану диспетчер появляется на этапе 1, после ручного
запуска на Kaggle одной командой.

Адрес сервера и токены — только в секретах, никогда в репозитории.
