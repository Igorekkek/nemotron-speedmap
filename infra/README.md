# Инфраструктура

Всё, что нужно, чтобы эксперимент запускался одной командой на нужном железе: `launch.py` для Kaggle,
агент для ноутбука и своих устройств, окружение, сборка llama.cpp (CUDA sm75 для T4, Vulkan для 780M).

Как устроено — `docs/infra.md`. Кода пока нет: первым появится `launch.py` и ручной запуск на Kaggle (этап 0).

Веса — не в `/kaggle/working` (это папка вывода Kaggle), а в `FASTINFER_CACHE`. Токены — только из
Kaggle Secrets, GitHub Secrets и файла окружения на сервере.
