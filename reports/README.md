# Отчёты

Сюда — выводы, которые выходят за рамки одного эксперимента, и еженедельные отчёты.

- Еженедельный отчёт: `ГГГГ-ММ-ДД-week.md` — что запускали, что узнали, что дальше.
- Сводный вывод по теме: `<тема>.md`, например `moe-speculation.md`, — со ссылками на папки в `experiments/`.

Цифры — только из записанных результатов, со ссылкой на эксперимент и коммит.
